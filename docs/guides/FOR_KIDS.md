# Utah Browser — guide for kids

Hi! This guide is for **you** — kids, families, and anyone who wants the simple version.

## What is Utah Browser?

Utah Browser is a **web browser** on your computer. It lets you visit websites, just like other browsers.

What makes it special:

- **It does not spy on you.** It keeps your work on *your* computer.
- **Truth Guard** is like a helpful fact-checker friend. It reads your **notebooks** (your notes and files) and helps you see if something online might not match what you already know.

Think of Truth Guard as: *“Does this match my notebook?”*

## The parts you can see

```
┌─────────────────────────────────────────────┐
│  Utah Browser    [ web address ]  [ Go ]    │  ← top bar
├─────────────────────────────────────────────┤
│ Tools │                                     │
│ panel │     the website you are visiting    │  ← big area
│       │                                     │
└─────────────────────────────────────────────┘
                    Truth HUD (pop-up)  ← warnings appear here
```

- **Address bar** — type where you want to go (like `https://example.com`), then press **Go**.
- **Tools** — opens the side panel for Truth Guard.
- **Truth HUD** — a small window that shows fact-check messages.

## How to use Truth Guard (easy steps)

1. Ask a grown-up to **set up** the browser once (they use the [Easy start guide](FOR_EVERYONE.md)).
2. Open **Tools** on the left.
3. Press **Ingest Notebooks** so the browser learns from your family’s note files.
4. Copy a sentence from a video or webpage into **Verify statement**.
5. Press **Verify**.
6. If something looks wrong, open **Truth HUD** to read the message.

Green-ish messages often mean: *“This matches your notebooks.”*  
Warning colors mean: *“Double-check this — it might not match.”*

## Rules for staying safe online

- **Ask a parent or teacher** before visiting new sites.
- **Do not share** passwords, home address, or phone number in chats.
- Truth Guard helps with **facts in your notebooks** — it is not magic and can make mistakes. Always ask a grown-up if you are unsure.
