# Utah Browser: Sovereign Product Overview

**The first truly sovereign workstation for the Utah-Omega-23 timeline.**

Utah Browser is a **privacy-first desktop web shell for Windows** built in Rust. It utilizes the system **WebView2** runtime to deliver high-performance browsing without the bloat of traditional Chromium or Electron deployments.

## The Sovereign Pillar

Utah is built on the **Truth-Lens paradigm**: the belief that search and browsing should be a process of verification against your own knowledge, not discovery through a commercial filter.

### Core Capabilities:
1. **Fluidic Spatial Topography:** A volumetric, hardware-accelerated UI that moves with you.
2. **The Sovereign Oracle:** Local RAG (Ollama + Qdrant) that indexes your history and files for instant, private querying.
3. **P2P Search Mesh:** A decentralized search engine that works without tracking or censorship.
4. **Universal Reality Matrix:** Undetectable web automation driven by local Vision-Language Models.
5. **Sovereign Secure Shield:** Native Rust ad-blocking and threat-prevention engine.
6. **Absolute Privacy:** RAM-only incognito modes and native Tor routing (.onion support).
