# Release artifacts

Build demo zip locally:

```powershell
.\scripts\Build-Demo.ps1 -Zip
```

Output: `UtahBrowser-Demo-win64.zip` — upload to [GitHub Releases](https://github.com/utahisnotastate/utahbrowser/releases) with tag `v1.0-demo`.

Zips are gitignored; this folder documents the process only.
